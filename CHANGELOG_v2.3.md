# CHANGELOG – Portale interventi interno

## Versione 2.3 (02/10/2026) – allegati per tutti i tipi di intervento

- Foto e documenti si possono allegare con qualunque tipo di intervento
  (prima solo Edilizia e Idraulico). Restano i limiti di prima: fino a 5 file,
  PDF o immagini.
- Lo scenario Make "WebApp Segnalazioni (fornitori da tabella)" allega i file
  alla mail del fornitore (o alla mail allo studio quando nessuna ditta riceve
  la richiesta); per Li.Ca. restano nella cartella Dropbox dell'intervento.
- Numero di versione 2.3, data 02/10/2026.
- Invariati: webhook, campi inviati, controllo doppioni, conferma al contatto
  in loco, storico locale, chiavi `localStorage`.

Le versioni precedenti sono descritte in CHANGELOG_v2.2.md, CHANGELOG_v2.1.md e CHANGELOG_v2.0.md.
